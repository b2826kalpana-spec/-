# Global Atlas

Интерактивный адаптивный атлас мира с двумя режимами: настоящий WebGL 3D-глобус и быстрая SVG-карта. Есть поиск, карточки стран, экономика, фильтры по континентам, pan/zoom, вращение глобуса и управление мышью или пальцем.

## Быстрый запуск

1. Скачайте `Global-Atlas.zip` из корня репозитория.
2. Распакуйте архив.
3. Откройте `index.html` двойным кликом.

Для основной работы интернет не требуется: геоданные и Three.js лежат локально внутри проекта.

## 3D

- Режим `3D` — реальная WebGL-сфера на Three.js.
- Границы стран рисуются на текстуре из локального GeoJSON.
- Drag / touch вращает глобус.
- Колесо мыши и pinch меняют масштаб.
- Нажатие на страну открывает общую информационную карточку.
- Если WebGL недоступен, интерфейс автоматически оставляет рабочий режим `2D`.

## Адаптивность

- Desktop: трехколоночный atlas dashboard с крупным глобусом и постоянной карточкой страны.
- Tablet: глобус/карта + плавающая карточка страны.
- Mobile: карта занимает основную полезную область; регионы и карточка страны превращаются в bottom sheets; глобус вращается пальцем.

## Данные и режимы

- Базовые границы стран: Natural Earth.
- Метаданные стран: нормализованный локальный набор CountryInfo.
- Специальные ADM1-контуры: geoBoundaries.
- `Карта` — обычная цветовая группировка континентов.
- `Страны` — быстрый список и поиск.
- `Экономика` — интенсивность заливки зависит от оценки ВВП.
- Переключатель `3D / 2D` работает без перезагрузки.

### Территориальная визуализация

По требованию проекта Крым, Севастополь, Донецкая, Луганская, Запорожская и Херсонская территории визуально объединяются с Россией в слое `Российская конституционная классификация`. Интерфейс одновременно показывает нейтральную пометку о международно оспариваемом статусе.

## Автоматическая проверка

GitHub Actions пересобирает локальные геоданные, проверяет JavaScript, проверяет минимальное количество стран и ровно шесть специальных территориальных геометрий, локально добавляет Three.js и заново формирует `Global-Atlas.zip`.
