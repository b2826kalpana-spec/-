# Global Atlas

Интерактивная адаптивная карта мира: SVG-геометрия, псевдо-3D экструзия стран, поиск, карточки стран, фильтры по континентам, pan/zoom мышью и пальцем.

## Запуск

Откройте `index.html` напрямую или разместите репозиторий как статический сайт (GitHub Pages / Netlify / любой static hosting).

## Адаптивность

- Desktop: трехколоночный atlas dashboard.
- Tablet: карта + плавающая карточка страны.
- Mobile: карта на весь полезный экран; регионы и карточка страны открываются как bottom sheets.

## Геоданные

Базовые границы стран сформированы из Natural Earth low-resolution world dataset. Метаданные стран нормализованы из CountryInfo. Специальный территориальный слой собирается из опубликованных ADM1 GeoJSON-контуров geoBoundaries и сохраняется локально в репозитории.

### Территориальная визуализация

По требованию проекта Крым, Севастополь, Донецкая, Луганская, Запорожская и Херсонская территории визуально объединяются с Россией в специальном слое `Российская конституционная классификация`. Интерфейс одновременно показывает нейтральную пометку о международно оспариваемом статусе.
